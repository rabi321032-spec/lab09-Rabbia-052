
# MediTrack Validation Checklist
Version: 0.1

## Purpose
This checklist is used to check the MediTrack SRS for clarity, completeness, consistency and testability.

## Checklist

| ID | Item | Answer | Evidence | Where question came from |
|---|---|---|---|---|
| C-01 | Does every requirement have a unique ID? | | | Document quality |
| C-02 | Does each requirement describe a system behavior or constraint? | | | Document quality |
| C-03 | Does each requirement contain only one main action? | | | Document quality |
| C-04 | Are all requirements written in clear and understandable language? | | | Document quality |
| C-05 | Are vague words clearly defined in the requirements? | | | Document quality |
| C-06 | Are the appointment duration rules consistent? | | | Contradiction risk |
| C-07 | Does the SRS explain how simultaneous bookings will be prevented from causing double bookings? | | | Double booking risk |
| C-08 | Does the SRS specify a measurable response time for booking requests? | | | Performance risk |
| C-09 | Does the SRS specify when appointment reminders will be sent? | | | Patient risk |
| C-10 | Does the SRS specify who can access patient medical records? | | | Data privacy risk / Data Protection Officer |
| C-11 | Does the SRS specify how patient records will be protected? | | | Security risk / Data Protection Officer |
| C-12 | Does the SRS specify accessibility features for elderly patients? | | | Patient |
| C-13 | Does the SRS explain how emergency walk-in patients will be handled? | | | Emergency risk / Receptionist |
| C-14 | Does the SRS define how the system will handle busy Monday mornings? | | | Performance risk / Clinic Administrator |
| C-15 | Does the SRS allow doctors to manage their appointment duration? | | | Doctor |
| C-16 | Does the SRS specify the maximum number of active appointments a patient can book? | | | Patient |
| C-17 | Does the SRS explain how receptionists can book walk-in appointments? | | | Receptionist |
| C-18 | Does the SRS allow doctors to view their daily schedules? | | | Doctor |
